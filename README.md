## 📝 User Registration Form Using ReactJS
This project demonstrates a **ReactJS-based User Registration Form** with a custom API integration. It allows new users to be added and displayed seamlessly.

### 🔗 API Setup
1. Go to [MockAPI - Get API Endpoint](https://mockapi.io/clone/6a078ee4fa9b27c848fa2993).  
2. Copy the generated API link.  
3. Paste it into the `API_URL` variable inside **RegisterationForm.jsx**.
